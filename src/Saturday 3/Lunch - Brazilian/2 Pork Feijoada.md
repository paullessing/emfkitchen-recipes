# Pork Feijoada
Pork-shoulder and Polish-sausage black-bean stew, finished in the oven.

| Field  | Value                     |
|--------|---------------------------|
| Type   | meat                      |
| Feeds  | 70                        |

| Day    | Saturday 3                |
| Meal   | Lunch                     |
| Theme  | Brazilian                 |

## Ingredients

| Ingredient      | Catering | Home | Prep                     |
|-----------------|----------|------|--------------------------|
| Polish Sausages | 7 kg     |      | Sliced into 0.5cm rounds |
| Pork Shoulder   | 7 kg     |      | 1-2 inch cubes           |
| Black Beans     | 15 kg    |      |                          |
| Onions          | 10 kg    |      | Chopped large (2 inch)   |
| Red Peppers     | 7 Kg     |      | Chopped medium (1 inch)  |
| Garlic          | 0.5 kg   |      |                          |
| Bay Leaves      | 0.1 kg   |      |                          |
| Stock           | 10 L     |      |                          |

## Method

1. Brown the sausage and pork and set aside.
2. Fry onions until soft, add garlic.
3. Add the peppers and fry.
4. Return the meat; add bay leaves and stock, simmer to meld.
5. Drain the black beans (keep the liquid); mash a third, add all the beans and simmer to thicken.
6. Season with salt, pepper and a splash of lime.
7. Loosen with the reserved bean liquid if needed.
