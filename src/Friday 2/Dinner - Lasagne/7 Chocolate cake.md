# Chocolate cake
One-bowl vegan chocolate traybake with a cocoa-icing top.

| Field | Value    |
|-------|----------|
| Type  | dessert  |
| Diet  | Vegan    |
| Day   | Friday 2 |
| Meal  | Dinner   |
| Theme | Lasagne  |

## Ingredients

| Ingredient    | Catering | Home | Prep |
|---------------|----------|------|------|
| Sugar         | 5.8 kg   |      |      |
| Cocoa Powder  | 0.725 kg |      |      |
| Baking Powder | 150 g    |      |      |
| Salt          | 75 g     |      |      |
| Flour         | 5.8 kg   |      |      |
| Water         | 6.96 l   |      |      |
| Oil           | 2.9 l    |      |      |
| Icing Sugar   | 6.96 kg  |      |      |
| Cocoa powder  | 0.725 kg |      |      |

## Method

1. Mix the dry: flour, sugar, cocoa, baking powder and salt.
2. Add water and oil; mix to a smooth batter.
3. Bake in trays until a skewer comes out clean.
4. Cool, then ice with icing sugar + cocoa + water.
