# Green salad with dressing
Leaf salad with tomatoes in a balsamic dressing.

| Field | Value    |
|-------|----------|
| Type  | cold     |
| Diet  | Vegan    |
| Day   | Friday 2 |
| Meal  | Dinner   |
| Theme | Lasagne  |

## Ingredients

| Ingredient       | Catering | Home | Prep |
|------------------|----------|------|------|
| Lettuce          | 80 ea    |      |      |
| Balsamic vinegar | 2 l      |      |      |
| Olive Oil        | 2 l      |      |      |
| Tomatoes         | 10 kg    |      |      |

## Method

1. Whisk olive oil and balsamic into a dressing.
2. Keep leaves and tomatoes cold.
3. Dress only at service.
