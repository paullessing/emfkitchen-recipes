# Pesto
Nut-free pesto from toasted sunflower & pumpkin seeds, garlic, basil and parsley.

| Field  | Value    |
|--------|----------|
| Type   | side     |
| Feeds  | 50       |
| Vessel | 3kg      |
| Diet   | Vegan    |
| Day    | Friday 2 |
| Meal   | Dinner   |
| Theme  | Lasagne  |

## Ingredients

| Ingredient      | Catering | Home | Prep |
|-----------------|----------|------|------|
| Sunflower Seeds | 0.5 kg   |      |      |
| Pumpkin seeds   | 0.5 kg   |      |      |
| Olive Oil       | 0.75 L   |      |      |
| Garlic          | 0.75 kg  |      |      |
| Basil           | 0.5 kg   |      |      |
| Fresh Parsley   | 0.3 kg   |      |      |

## Method

1. Toast the seeds.
2. Blend seeds, garlic, basil, parsley and olive oil to a coarse pesto.
3. Season.
