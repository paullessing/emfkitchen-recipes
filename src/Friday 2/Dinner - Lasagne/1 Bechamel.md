# Bechamel
White sauce for the lasagne.

| Field  | Value            |
|--------|------------------|
| Type   | side             |
| Feeds  | 60 litres        |
| Vessel | topf             |
| Diet   | Vegan            |
| Day    | Friday 2         |
| Meal   | Dinner           |
| Theme  | Lasagne          |
| Label  | Vegan (oat milk) |

## Ingredients

| Ingredient   | Catering | Home | Prep |
|--------------|----------|------|------|
| Flour        | 4 kg     |      |      |
| Margarine    | 6 kg     |      |      |
| Oat Milk     | 46 L     |      |      |
| Salt         | 360 g    |      |      |
| White Pepper | 100 g    |      |      |

## Method

1. Melt the margarine.
2. Add the flour and cook out to a roux.
3. Add the oat milk and stir constantly until boiled.
4. Season with salt and white pepper.
