# Coleslaw
Red & white cabbage and carrot slaw with spring onion in a cider-vinegar dressing.

| Field | Value    |
|-------|----------|
| Type  | cold     |
| Diet  | Vegan    |
| Day   | Friday 2 |
| Meal  | Lunch    |
| Theme | Texmex   |

## Ingredients

| Ingredient          | Catering | Home | Prep |
|---------------------|----------|------|------|
| Red Cabbage         | 9 kg     |      |      |
| White Cabbage       | 9 kg     |      |      |
| Spring Onions       | 2 kg     |      |      |
| Carrots             | 9 kg     |      |      |
| Apple Cider Vinegar | 2 l      |      |      |
| Oil                 | 3 l      |      |      |

## Method

1. Shred the cabbages and grate the carrot (machine); slice the spring onions.
2. Knead the cabbage with salt until tender.
3. Mix in the carrot and spring onion.
4. Season with oil and cider vinegar; chill until service.
