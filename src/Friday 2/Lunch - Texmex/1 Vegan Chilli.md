# Vegan Chilli
Four-bean chilli in a spiced tomato base.

| Field  | Value         |
|--------|---------------|
| Type   | vegmain       |
| Feeds  | 200           |
| Vessel | Kipper first! |
| Diet   | Vegan         |
| Day    | Friday 2      |
| Meal   | Lunch         |
| Theme  | Texmex        |

## Ingredients

| Ingredient       | Catering | Home | Prep        |
|------------------|----------|------|-------------|
| Onions           | 20 kg    |      | Diced 1inch |
| Black beans      | 10 kg    |      | Drained     |
| Kidney beans     | 10 kg    |      | Drained     |
| Tinned Chickpeas | 10 kg    |      | Drained     |
| Pinto beans      | 10 kg    |      | Drained     |
| Tinned Tomatoes  | 14 kg    |      |             |
| Red Peppers      | 4 kg     |      | Diced 1inch |
| Cumin            | 0.2 kg   |      |             |
| Smoked Paprika   | 0.2 kg   |      |             |
| Chilli Powder    | 0.2 kg   |      |             |
| Cayenne Pepper   | 0.2 kg   |      |             |
| Tomato Puree     | 2.5 kg   |      |             |

## Method

1. Fry onions with the spices (cumin, smoked paprika, chilli, cayenne) until golden.
2. Add tomato purée and tinned tomatoes; scrape the base.
3. Add all the beans (black, kidney, chickpea, pinto) with a little bean water.
4. Add red peppers; simmer to a good consistency.
5. Season to taste.
6. Loosen with stock if it gets too dry.
