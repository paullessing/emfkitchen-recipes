# Coconut custard
Coconut-flavoured custard thickened with cornflour; oat-milk batch for vegans.

## Ingredients

| Ingredient         | Catering | Home | Prep |
|--------------------|----------|------|------|
| Milk               | 50 l     |      | 37   |
| Oat Milk           | 15 l     |      | 11.1 |
| Sugar              | 6 kg     |      | 6.0  |
| Cornflour          | 4 kg     |      | 4.0  |
| Coconut flavouring | 2 ea     |      |      |

## Method

1. Whisk cornflour and sugar with a little cold milk.
2. Heat the rest of the milk with coconut flavouring; whisk in the slurry and cook to thicken.
3. Make a separate oat-milk batch — label it.
