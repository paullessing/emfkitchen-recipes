# Chilli Vinegar
Sharp table condiment of vinegar, bird's-eye chilli and garlic, blitzed.

| Field | Value      |
|-------|------------|
| Type  | cold       |
| Diet  | Vegan      |
| Day   | Thursday 1 |
| Meal  | Dinner     |
| Theme | Thai       |

## Ingredients

| Ingredient              | Catering | Home | Prep          |
|-------------------------|----------|------|---------------|
| Distilled white vinegar | 4 L      |      |               |
| Birds Eye Chilies       | 200 g    |      | Stems removed |
| Garlic                  | 200 g    |      | Peeled        |

## Method

1. Blitz the vinegar, chillies and garlic together.
2. Hold in bottles/jars for the tables.
