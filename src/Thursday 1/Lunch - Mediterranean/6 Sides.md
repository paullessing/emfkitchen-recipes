# Sides
Accompaniments for the shawarma: hummus, chilli sauce, pickled vegetables and reheated pitta.

| Field | Value         |
|-------|---------------|
| Type  | side          |
| Feeds | 130           |
| Diet  | Mixed         |

| Meal  | Lunch         |
| Theme | Mediterranean |

## Ingredients

| Ingredient         | Catering | Home | Prep                                    |
|--------------------|----------|------|-----------------------------------------|
| Hummus             | existing |      |                                         |
| Chili Sauce        | 3 ea     |      |                                         |
| Pickled Vegetables | 8 kg     |      |                                         |
| Pitta Bread        | 200 ea   |      | cut in half (across) and reheat in oven |

## Method

1. Cut the pitta in half across and reheat in the oven.
2. Put out hummus (~50g pp), chilli sauce and pickled vegetables.
