# Zwiebelkuchen
German onion tart: a yeast-dough base topped with caramelised onions and caraway, baked in trays. Dough is made the day before.

## Ingredients

| Ingredient    | Catering | Home | Prep                                      |
|---------------|----------|------|-------------------------------------------|
| Onions        | 30 kg    |      | peeled, halved, sliced VPM medium setting |
| Flour         | 9 kg     |      |                                           |
| Yeast         | 150 g    |      |                                           |
| Margarine     | 10 kg    |      |                                           |
| Soy Milk      | 2 l      |      |                                           |
| Oil           | 600 ml   |      |                                           |
| Caraway Seeds | 350 g    |      |                                           |

## Method

1. Slice the onions (machine).
2. Sweat until soft, then caramelise.
3. Roll out the pre-made dough.
4. Line the GNs with baking paper.
5. Press the dough into the GN.
6. Spread caramelised onions and caraway seeds on top.
7. Bake ~220°C for ~30 min until set and golden.

## Notes

**Dough made the previous day** (flour, yeast, margarine, soy milk, oil, caraway) — see the Mon −2D pre-prep.
