# Kartoffelsuppe (Potato Soup)
Hearty potato and brown-lentil soup with carrots and mushrooms, seasoned with marjoram.

| Field  | Value      |
|--------|------------|
| Type   | vegmain    |
| Vessel | Kipper     |
| Diet   | Vegan      |
| Day    | Tuesday -1 |
| Meal   | Lunch      |
| Theme  | German     |

## Ingredients

| Ingredient      | Catering | Home | Prep                   |
|-----------------|----------|------|------------------------|
| Onions          | 23 kg    |      | chopped 1inch          |
| Potatoes        | 30 kg    |      | peeled and cubed 1inch |
| Carrots         | 15 kg    |      | peeled and cubed 1inch |
| Mushrooms       | 7.5 kg   |      | chopped 1inch          |
| Brown Lentils   | 15 kg    |      |                        |
| Marjoram        | 200 g    |      |                        |
| Vegetable Stock | 1 kg     |      |                        |

## Method

1. Sweat the onions.
2. Add potatoes, carrots, mushrooms and marjoram.
3. Add the brown lentils and vegetable stock.
4. Simmer until potatoes and lentils are tender.
5. Season, and partially blend for a thicker body.
