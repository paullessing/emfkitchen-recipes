# Beef & Ale Stew
Beef is browned off, vegetables sweated in the same pan. Deglaze with ale, simmer with stock, and thicken with Bisto at the end.

## Ingredients

| Ingredient      | Catering | Home | Prep                  |
|-----------------|----------|------|-----------------------|
| Beef, Stewing   | 7.5 kg   |      |                       |
| Pepper, Cracked | 100 g    |      |                       |
| Ale             | 6 l      |      |                       |
| Flour           | 1.5 kg   |      |                       |
| Onions          | 10 kg    |      | medium cubes          |
| Carrots         | 6 kg     |      | peeled, machine cubes |
| Swede           | 5 kg     |      | peeled, machine cubes |
| Bisto           | 300 g    |      |                       |

## Method

1. Toss beef in flour mixed with cracked pepper; shake off excess.
2. Sear beef in minimal oil, in batches, until deep brown. Remove.
3. Fry onions, carrots and swede in the same pan.
4. Deglaze with ale, scraping the base clean.
5. Return beef; add stock and/or more ale to cover.
6. Simmer gently until beef is fork-tender and sauce coats a spoon.
7. Stir in Bisto to thicken; taste and season.
