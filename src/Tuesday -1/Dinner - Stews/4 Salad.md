# Salad
Leaf salad with an oil, balsamic and Dijon dressing, combined only at service.

| Field | Value               |
|-------|---------------------|
| Type  | cold                |
| Diet  | Vegan               |
| Day   | Tuesday -1          |
| Meal  | Dinner              |
| Theme | Stews               |
| Label | Vegan · gluten-free |

## Ingredients

| Ingredient       | Catering | Home | Prep    |
|------------------|----------|------|---------|
| Lettuce          | 50 ea    |      | defrost |
| Oil              | 2 L      |      |         |
| Balsamic Vinegar | 2 L      |      |         |
| Dijon Mustard    | 1 kg     |      |         |

## Method

1. Whisk oil, balsamic and Dijon into a smooth emulsion.
2. Dress the leaves only at service; toss just before serving.
