# Potato Wedges
Skin-on wedges in smoked-paprika oil, roasted.

| Field | Value    |
|-------|----------|
| Type  | side     |
| Diet  | Vegan    |
| Day   | Sunday 4 |
| Meal  | Lunch    |
| Theme | Burgers  |

## Ingredients

| Ingredient     | Catering | Home | Prep |
|----------------|----------|------|------|
| Potatoes       | 70 kg    |      |      |
| Smoked Paprika | 0.5 kg   |      |      |
| Olive Oil      | 1 l      |      |      |

## Method

1. Toss the potatoes in oil and smoked paprika.
2. Roast until crisp.
