# Sides
Burger assembly: buns, cheese, sliced and fried onions, lettuce, tomato and sauces.

| Field | Value    |
|-------|----------|
| Type  | side     |
| Diet  | Assembly |
| Day   | Sunday 4 |
| Meal  | Lunch    |
| Theme | Burgers  |

## Ingredients

| Ingredient    | Catering | Home | Prep                                                                 |
|---------------|----------|------|----------------------------------------------------------------------|
| Burger Buns   | 512 ea   |      |                                                                      |
| Cheese Slices | 400 ea   |      |                                                                      |
| Red Onions    | 6 kg     |      | Slice into thin rings                                                |
| Onions        | 10 kg    |      | Sweated down (use the middle bits left over from making onion rings) |
| Lettuce       | 7 ea     |      |                                                                      |
| Tomatoes      | 3 kg     |      |                                                                      |
| Ketchup       | 3 kg     |      |                                                                      |
| Mayo          | 2 kg     |      |                                                                      |
| Mayo, Vegan   | 1 kg     |      |                                                                      |
| Mustard       | 1 kg     |      | Plus any leftover dips                                               |

## Method

1. Set up the assembly line: buns, cheese slices, thin-sliced red onion, sweated onions, lettuce and tomato.
2. Put out ketchup, mayo (dairy + vegan), mustard and any leftover dips.
