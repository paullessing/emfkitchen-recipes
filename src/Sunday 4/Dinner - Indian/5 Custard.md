## Ingredients

| Ingredient     | Catering | Home | Prep |
|----------------|----------|------|------|
| Milk           | 100 l    |      |      |
| Oat Milk       | 20 l     |      |      |
| Sugar          | 7 kg     |      |      |
| Custard Powder | 7 kg     |      |      |

## Method

1. Whisk custard powder and sugar with a little cold milk to a paste.
2. Heat the rest of the milk, whisk in the paste and cook until thickened.
3. Make a separate oat-milk batch — label it.
