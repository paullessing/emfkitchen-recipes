## Ingredients

| Ingredient            | Catering | Home | Prep   |
|-----------------------|----------|------|--------|
| Onions                | 16 kg    |      | Sliced |
| Garlic Paste          | 360 g    |      |        |
| Ginger Paste          | 400 g    |      |        |
| Kashmir Chilli Powder | 44 g     |      |        |
| Tomato puree          | 360 g    |      |        |
| Tinned Tomatoes       | 7.5 kg   |      |        |
| Tomato puree          | 720 g    |      |        |
| Sugar                 | 40 g     |      |        |
| Garam Masala          | 16 g     |      |        |
| Cumin                 | 12 g     |      |        |
| Frozen Peas           | 10 kg    |      |        |
| Paneer                | 10 kg    |      |        |
| Cream, Double         | 2 L      |      |        |

## Method

1. Caramelise the onions deep brown.
2. Add garlic and ginger paste; fry golden.
3. Add chilli powder, tomato purée and salt.
4. Add tinned tomatoes and cook until broken down.
5. Add garam masala, cumin and sugar; simmer to a masala base.
6. Reheat the masala; add peas and a little water, cook through.
7. Add the paneer and simmer.
8. Stir in the cream and heat gently — don't boil.
