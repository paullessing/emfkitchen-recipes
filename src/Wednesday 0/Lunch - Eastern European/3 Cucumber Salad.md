# Cucumber Salad
Salted cucumber slices, drained then dressed with garlic, sour cream, lemon and paprika.

| Field | Value                    |
|-------|--------------------------|
| Type  | cold                     |
| Diet  | Vegetarian               |
| Day   | Wednesday 0              |
| Meal  | Lunch                    |
| Theme | Eastern European         |
| Label | Vegetarian · vegan batch |

## Ingredients

| Ingredient        | Catering | Home | Prep                   |
|-------------------|----------|------|------------------------|
| Cucumber          | 65 ea    |      | Peel, Machine Slice    |
| Garlic            | 0.2 kg   |      | Pureed                 |
| Sour Cream        | 2 kg     |      |                        |
| Sour Cream, Vegan | 0.4 kg   |      |                        |
| Paprika           | 50 g     |      |                        |
| Lemon Juice       | 1 l      |      |                        |
| Salt              | 500 g    |      | approx, please be sane |

## Method

1. Peel and slice the cucumbers.
2. Salt and refrigerate at least 1 hour.
3. Drain well.
4. Mix with garlic, sour cream (dairy + vegan), lemon juice and paprika.
