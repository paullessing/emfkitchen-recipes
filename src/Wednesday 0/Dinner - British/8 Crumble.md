# Crumble
Deconstructed crumble — the topping is baked separately until crisp and the apples are stewed, then served together.

## Ingredients

| Ingredient | Catering | Home | Prep                      |
|------------|----------|------|---------------------------|
| Margarine  | 5 kg     |      |                           |
| Flour      | 6.5 kg   |      |                           |
| Oats       | 3.25 kg  |      |                           |
| Sugar      | 6.5 kg   |      |                           |
| Apples     | 65 kg    |      | Peeled and cubed into 2cm |
| Sugar      | 5 kg     |      |                           |
| Cinnamon   | 200 g    |      |                           |
| Nutmeg     | 50 g     |      |                           |

## Method

1. Make the crumble: melt the margarine and mix through the flour, oats, sugar, cinnamon and nutmeg.
2. Spread into GNs and bake at 200°C until dry and crisp.
3. Put the apples in a big pot or kipper with sugar to taste.
4. Sweat until softened (not too long); add a splash of water if needed.
5. Serve the stewed apples with the crisp crumble on top.
