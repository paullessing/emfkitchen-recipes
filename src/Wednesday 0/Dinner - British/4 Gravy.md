# Gravy
Onion gravy on caramelised onions and (optionally) sausage fat, thickened with GF flour and Bisto; keep a veg pot aside.

## Ingredients

| Ingredient        | Catering | Home | Prep |
|-------------------|----------|------|------|
| Onions            | 50 kg    |      |      |
| Ale               | 4 l      |      |      |
| Stock             | 50 L     |      |      |
| Gluten Free Flour | 3 kg     |      |      |
| Bisto             | 400 g    |      |      |
| Sausage fat       | existing |      |      |

## Method

1. Caramelise the onions.
2. Reserve some onions for a separate veg pot.
3. Add sausage fat to the main pot.
4. Add GF flour and fry until brown.
5. Deglaze and top up with stock (and ale/stout).
6. Simmer through and finish with Bisto.
