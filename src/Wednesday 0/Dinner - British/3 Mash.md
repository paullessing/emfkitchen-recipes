# Mash
Potato mash loosened with margarine and oat milk, with fried leftover cabbage folded through.

## Ingredients

| Ingredient             | Catering | Home | Prep                  |
|------------------------|----------|------|-----------------------|
| Potatoes               | 70 kg    |      | Peeled, chopped large |
| Margarine              | 8 kg     |      |                       |
| Oat Milk               | 10 L     |      |                       |
| Fried leftover cabbage | existing |      |                       |

## Method

1. Boil the potatoes, drain and mash.
2. Add margarine and oat milk.
3. Reheat the leftover cabbage and fold it through.
4. Season with salt and white pepper.
